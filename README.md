# 多无人机动态协同调度算法——两分钟汇报提纲

## 一、核心算法

- **A* 路径规划**：地图建模为带权无向图，计算实际航路距离。
- **贪心订单分配**：通过评分函数选择最优候选订单。
- **热点区域预调度**：根据区域评分，提前调度空闲无人机。
- **动态状态更新**：新订单触发调度，更新任务执行与充电状态。

## 二、订单分配策略

1. **约束筛选**：载重限制、截止时间、电量安全阈值。
2. **综合评分**：

   $$
   f(i,j)=\frac{\alpha_f}{1+d}+\frac{\beta_f}{1+s}+\frac{\gamma_f}{1+E}
   $$

   - $d$：实际飞行距离
   - $s$：预计送达后的时间裕量
   - $E$：预计耗电量

3. **贪心分配**：逐架无人机选择最高评分订单，立即执行。

## 三、空闲无人机预调度

1. **地图网格化**：划分待命区域。
2. **区域评分**：

   $$
   g(i,k)=\alpha_gq_k+\frac{\beta_g}{1+n_k}+\frac{\gamma_g}{1+d_{ik}}
   $$

   - $q_k$：区域累计订单数量
   - $n_k$：区域已有或即将到达的待命无人机数量
   - $d_{ik}$：无人机到目标区域的航路距离

3. **预调度目标**：兼顾订单需求、无人机分布与调度成本。

## 四、动态调度与电量管理

- **订单驱动**：新订单到达时触发调度。
- **状态管理**：空闲、配送、待命移动、充电。
- **自动充电**：低电量触发原地充电，充满后恢复空闲。
- **任务更新**：根据预计完成时间更新位置与状态。

## 五、实现情况与后续优化

- **已实现**：C++ 调度原型、A* 航路搜索、双评分函数、贪心分配、状态更新。
- **现存局限**：评分权重未验证；不支持多单合送、航路冲突处理及连续实时调度。
- **优化方向**：通过订单完成率、平均配送时间、总航程及能耗进行仿真评估与参数优化。
